People, data, and software

Credits & Licenses

Last updated: November 9, 2026

HluWeatherApp is built with data and software from the providers and projects listed below. Weather, radar, map, geocoding, and routing services are contacted directly by the app when their features are used.

The app's source code is licensed under GNU General Public License version 3. Service terms and data licenses can change; please follow the linked providers' current terms.

Weather and location data

  • Open-Meteo provides weather and air-quality forecasts, trip-point forecasts, and geocoding. Open-Meteo API data are offered under Creative Commons Attribution 4.0 (CC BY 4.0). Please credit “Weather data by Open-Meteo.com.” Open-Meteo's license and data-sources page identifies upstream datasets and their individual terms.
  • MET Norway provides weather forecasts. Its open data require attribution under CC BY 4.0; see the MET API terms.
  • Visual Crossing Weather provides forecasts through its Timeline Weather API. Its anonymous no-key service requires visible attribution near displayed weather: “Weather data provided by Visual Crossing Weather,” linked to Visual Crossing where practical. Access is subject to current service terms and fair-use controls; the service does not promise a fixed request allowance.
  • Bright Sky provides a free API for Deutscher Wetterdienst (DWD) Open Data. The app places “Weather data via Bright Sky” and “Source: Deutscher Wetterdienst” next to Bright Sky forecasts, linking to Bright Sky and DWD’s source-acknowledgement guidance. Bright Sky states that DWD’s terms apply; DWD’s open spatial data are reusable under CC BY 4.0 with source acknowledgement.
  • Photon by Komoot powers one of the place-search options. Photon software is licensed under Apache License 2.0; its search data are based on OpenStreetMap and are subject to the OpenStreetMap ODbL terms.
  • Nominatim (OpenStreetMap) is used for reverse geocoding. The underlying OpenStreetMap data are licensed under the Open Database License (ODbL) 1.0. The public service has a separate usage policy.
  • OSRM (Open Source Routing Machine) calculates driving routes. OSRM software is licensed under the BSD 2-Clause License; route data are based on OpenStreetMap (ODbL).

Radar data

  • LibreWXR provides one of the precipitation-radar options. Its data sources include EUMETNET OPERA, NOAA Enterprise Rain Rate (RRQPE), and Radar-DPC (Italy; CC BY-SA 4.0 where included). See the LibreWXR data-sources details for current credits and terms.
  • RainViewer provides the other radar option. Its public radar API is for personal, educational, and small-scale community use; see the current RainViewer API terms and source information.

Map data and attribution

Map styles and vector tiles are served by OpenFreeMap and use the OpenMapTiles schema and OpenStreetMap data. OpenFreeMap's project is MIT-licensed. OpenMapTiles code is BSD-3-Clause and its cartographic design is CC BY 4.0. OpenStreetMap data are licensed under ODbL 1.0.

The map's required attribution is shown by the map renderer: OpenFreeMap © OpenMapTiles Data from OpenStreetMap. Read the OpenStreetMap attribution guidance, OpenMapTiles license, and OpenFreeMap license and terms.

Open-source libraries

The app uses these primary runtime libraries. Each project's license and source repository are linked; versions are maintained in the project's Gradle version catalog.

  • AndroidX and Jetpack Compose — Android Core KTX, Compose UI, Material 3 and icons, Activity, Lifecycle, Navigation, DataStore, WorkManager, and Glance. Licensed under Apache License 2.0. Project information.
  • Kotlin and kotlinx libraries — Kotlin standard library, Coroutines, Serialization, and DateTime. Licensed under Apache License 2.0. Kotlin source.
  • Ktor Client — HTTP networking. Licensed under Apache License 2.0.
  • MapLibre Compose — Compose map integration, licensed under BSD 3-Clause. It uses MapLibre Native, licensed under BSD 2-Clause.
  • Google Play services Location — used only in the Google distribution of the app; subject to Google Mobile Developer Services terms.

These entries identify the app's primary direct runtime libraries. Transitive components may carry their own notices; refer to the linked project repositories and license files for their complete notices.
